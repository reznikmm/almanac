This branch has a stripped version of libraries to fit them on STM32 MCU.
Embedded runtimes doesn't have Direct_IO nor Generic_Real_Arrays packages,
so they were replaced with a custom code.

Embedded data includes a record:
* From: 2019-12-15 00:00:00
* To: 2040-01-07 00:00:00


 *Ada functions for astronomical calculations*

This repository contains two Ada crates that are available from  [Alire](https://alire.ada.dev).

-   [Ephemeris](ephemeris) is an Ada library for getting ephemerides of celestial bodies. 

-   [Astro](astro) is an Ada library of functions for carrying out astronomical calculations 
	such as those required to build 	the [astronomical almanac](https://aa.usno.navy.mil/publications/asa).
